# 🔬 Idris2-Hadron3

**Quark-to-Hadron Algebraic Functor & Confinement for Idris 2**

`Idris2-Hadron3` models subatomic strong interactions:
- **Quark-to-Hadron Functor**: Direct categorical mapping from $3$-quark/anti-quark multisets into color-singlet hadrons.
- **Color Confinement**: Elliptic sector bound-state confinement ($3 \times 3 \times 3 = 27$ Vexel-Maxels).

---

## 🚀 Building & Installing

Built with Idris 2 (`0.8.0`):

```bash
idris2 --build Idris2-Hadron3.ipkg
idris2 --install Idris2-Hadron3.ipkg
```
